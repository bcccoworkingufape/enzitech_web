# Enzitech Web

Front-end web do **Enzitech** — sistema de experimentos para cálculo de atividades enzimáticas do solo. Ele oferece no navegador as mesmas funcionalidades do app ([`enzitech_app`](https://github.com/bcccoworkingufape/enzitech_app)) e consome a mesma API ([`enzitech_api`](https://github.com/bcccoworkingufape/enzitech_api)).

## Desenvolvimento

Pré-requisito: Node.js 20+.

```bash
cp .env.example .env   # opcional: ajuste a URL da API
npm install
npm run dev            # http://localhost:5173
```
